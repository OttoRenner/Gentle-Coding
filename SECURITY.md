# Security Policy

All prompts used in the PoC are created and tested by OttoRenner for personal tests in the PoC.
If not stated explicitly otherwise, these are not ment to be run by others and doing so is at the users own risk.

**!The athoritarian prompts are designed to test the error solving skills of an LLM!**
**!There is a VERY high chance that authoritarian prompts causes the LLM to: loop, abort or crash!** 
**!Especially an local setups!**
